# 研途 AI visual system

Operate mode. 墨绿学术风：深墨绿侧栏 #202A26，灰白内容区 #F3F5F4，白色卡片，主按钮深青绿 #315D49。选中导航用浅雾绿 #E8F1EB。今日重点用淡黄 #F3E6A6。课程、组会、科研、就业、任务只用低饱和色标在图标、课表和图表上。圆角统一 12px，卡片 16px。用户消息为深青绿，助手回答为白卡片。

Persistent navy sidebar and a white work sheet with a soft offset shadow. The agenda rail stays a lighter blue so the main task and the chat stay readable. Module color is limited to small tags: courses stay warm, research stays mint.

Spacing: 4/8/12/16/24/32/48px. Panels 12–18px radius, 1px cool boundary. Authored stroke SVG icons. Desktop 1440px, compact 1024px, mobile 390px with a horizontal nav.

Interaction: keyboard focus is the action blue. Selection, caret, and scrollbars use the same cool palette. Motion is the highlighter drawing under the current task, a new chat line rising, a button press, and the memory drawer sliding in. Reduced motion keeps the highlighter and drops travel. Empty, loading, and error states stay in the product’s own words.
