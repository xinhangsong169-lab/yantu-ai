# 研途 AI

面向硕士、博士研究生的个人学术工作台。课程、组会、科研和就业共用一份可查看、可修改、可删除的个人记忆。

文献放在科研课题里，不单独做文献库。就业包含实习校招、选调与公务员、国企与央企，公告内容来自你粘贴的原文和官方入口，不编造在招岗位。

## 运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

打开 [http://127.0.0.1:5173](http://127.0.0.1:5173)。

不配置模型密钥时，组会整理、论文摘录和对话使用本地规则，并标明“本地整理”。配置阿里云百炼兼容接口后，对话和课表图片识别走云端模型：

```bash
cp .env.example .env
```

`.env` 中填写 `DASHSCOPE_API_KEY`。密钥只留在服务端。

## 演示时可以看的闭环

1. 工作台显示今天的课，以及日期最近的未完成任务。
2. 在组会里整理一段记录，确认后才写入任务和记忆。
3. 打开科研或就业助手，不需要重新介绍研究方向。
4. 在记忆里停用或删除一条内容，之后的回答不再使用它。
5. 就业页解析公告时，只对照你档案里写过的内容，不判断你已经符合报名资格。

当前首次进入会载入「林同学」演示档案。侧栏可以清空，或恢复演示。
